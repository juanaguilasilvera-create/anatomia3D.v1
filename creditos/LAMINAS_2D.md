# Referencias de láminas bidimensionales — V9

La aplicación enlaza imágenes de Wikimedia Commons bajo sus propias condiciones de licencia. No se presentan como fotografías de las mallas BodyParts3D. **Cada lámina dispone de un enlace directo a su página de origen**, donde pueden consultarse autoría, licencia y versiones. Las imágenes no están embebidas en el ZIP y requieren conexión a internet.

**Avisos de precisión:** El sistema nervioso del atlas 3D no incluye todos los nervios periféricos, aunque el esquema 2D sí puede mostrar la distribución general. La imagen histológica de cartílago representa tejido a otra escala; no se puede hacer zoom microscópico real sobre el modelo 3D. La captura del visor 3D es una representación del modelo, no una imagen radiológica o clínica. La función de subir imágenes permite cargar material de estudio propio, pero no lo valida científicamente.
